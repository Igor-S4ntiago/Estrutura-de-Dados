# Estrutura-de-Dados
Repositório contendo implementações, exercícios e projetos desenvolvidos durante a disciplina de Estrutura de Dados no curso de Engenharia de Software.

O objetivo deste repositório é aplicar conceitos fundamentais da ciência da computação relacionados à organização, manipulação e otimização de dados, 
utilizando diferentes estruturas e algoritmos amplamente utilizados no desenvolvimento de software.

  Objetivos

- Aplicar conceitos teóricos de Estruturas de Dados na prática

- Desenvolver raciocínio lógico e pensamento algorítmico

- Implementar estruturas eficientes para manipulação de dados

- Compreender a análise de complexidade de algoritmos


    Conteúdos Abordados

- Listas encadeadas (simples e duplamente encadeadas)

- Pilhas (Stacks)

- Filas (Queues)

- Árvores                                          

- Algoritmos de busca

- Algoritmos de ordenação

- Análise de complexidade (Big-O)
  

Tecnologias Utilizadas

- Linguagem: C++

- Controle de versão: Git & GitHub
